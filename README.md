# MOAntiSpy

《心灵终结 3.3.6》（Mental Omega 3.3.6）的客户端插件。

> ## ⚠️ 使用范围
>
> **建议仅 PVE / 单人战役 / 人机对战使用。**
>
> **禁止在 PVP（玩家对玩家）中使用。** 它会让间谍几乎无法使用，严重破坏对抗平衡。

## 功能

己方单位、建筑会自动优先攻击**攻击范围内**的敌方间谍。

- 全图扫描，不限于当前选中的单位；
- 只处理己方、有武器、且武器能对地的对象（纯对空武器如爱国者不参与）；
- 判定距离用该单位自己的武器射程，间谍进入射程才会被处理；
- 每个单位每次扫描最多发一条指令，目标取范围内最近的间谍。

## 安装

1. 需要先安装 [Syringe](https://github.com/Ares-Developers/Syringe)（心灵终结自带）。
2. 把以下三个文件放进游戏根目录（`gamemd.exe` 所在目录）：
   - `MOAntiSpy.dll`
   - `MOAntiSpy.dll.inj`
   - `MOAntiSpy.ini`
3. 启动游戏即可。

## 配置

```ini
[AntiSpy]
Enable=1
Interval=15      ; 扫描间隔（逻辑帧），15 ≈ 半秒
SpyTypes=        ; 额外间谍类型 ID，逗号分隔；留空用内置列表
SkipAA=1         ; 1 = 纯对空武器不参与
Log=1            ; 1 = 写 MOAntiSpy.log
```

内置间谍类型：`SPY` `SPY2` `SPY3` `SPYF` `SPYG` `SPYS` `SABOT`。如果某个阵营的间谍没被识别，把它的类型 ID 填到 `SpyTypes=` 即可。

## 说明

- 纯客户端插件：只读对象状态并发送标准 Attack 事件，不修改模拟数据。
- 联机时对方无需安装（但请遵守上面的 PVP 限制）。
- 被重定向的单位会离开当前任务去攻击间谍，这是“优先攻击间谍”的必然结果；扫描间隔可调大以减少打断。
